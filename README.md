# Library Console Application

A seamless Library management system that allows a library to track books, borrowers, fines, and borrowing periods.

## Features
- Add, remove, and search books
- Register borrowers and track loans
- Apply fines for late returns
- Record all transactions

## How to Run
1. Open `LibraryManagement system final.slnx` in Visual Studio
2. Build the solution
3. Run the console application

## Tech Stack
- C#
- .NET Console Application
